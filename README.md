# Clippath Maker

Clippath maker is a nextjs project to allow the edition of clip-paths in a more personnalized way. work in progress and can be messy.

## Getting Started

First, run the development server:

```bash
npm i && npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
